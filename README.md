IPL Match & Player Performance Analysis

Project Overview
This project analyzes Indian Premier League (IPL) match and player performance data using Microsoft Excel. The interactive dashboard presents key statistics and visualizations to help explore team performance, player achievements, match results, and season-wise trends.

Dashboard Highlights
- **KPI Cards:** Total Matches, Total Runs, Total Wickets, Total Teams, and Total Seasons
- **Team Performance:** Top 5 teams by wins
- **Toss Analysis:** Batting vs. fielding decisions
- **Player Performance:** Top 10 run scorers and wicket takers
- **Season Analysis:** Matches played by season
- **Match Results:** Analysis of match outcomes
- **Player of the Match:** Players with the most awards

Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Data analysis and visualization
- Dashboard design and formatting

Key Skills Demonstrated
- Data summarization and analysis
- KPI development
- Chart creation and formatting
- Interactive data exploration using Excel features

Project Files
- `IPL_Match_and_Player_Performance_Analysis.xlsx` — Excel workbook containing the dashboard and analysis.

How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Dashboard sheet to explore the visualizations.
4. Use available filters or slicers, if configured, to explore the data.
